# STOCK POINT

GitHub Pagesを使った仮想株式市場です。

## 基本仕様

- 初期ポイント：5,000ポイント
- 株価変動：1時間ごと
- 購入・売却：GitHub Issuesから申請
- 取引処理：GitHub Actions
- データ保存：JSONファイル
- ランキング：総資産順
- 保有株・損益・取引履歴：公開

## 設置方法

1. 各ファイルをGitHubリポジトリに配置する。
2. app.jsのGitHubユーザー名とリポジトリ名を設定する。
3. Settings → Pagesを開く。
4. mainブランチのルートフォルダを公開元に設定する。
5. Settings → Actions → Generalでワークフローの書き込み権限を確認する。
6. Actionsタブで株価更新ワークフローを手動実行する。
7. Issuesから売買申請をテストする。

## 注意

このプロジェクトは学習用の仮想市場です。
ポイントは現金価値を持ちません。

公開リポジトリでは取引履歴やプレイヤー名が公開されます。
秘密鍵やパスワードを公開ファイルに保存しないでください。

GitHub Actionsのスケジュールは遅延することがあります。
また、この試作は厳密な同時取引制御や完全な不正防止を保証しません。
